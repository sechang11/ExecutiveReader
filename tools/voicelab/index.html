Voice lab

Measures how the neural engine actually renders a piece of punctuation, by synthesizing variants of the same sentence and reporting the audio duration. It answers questions that reading the vocabulary file cannot: a token being in the vocabulary proves the model was trained with one, not that the output sounds right.

It deliberately skips normalize(), because the point is usually to measure what a normalization rule would change.

Run: node tools/serve-repo.mjs, then open http://localhost:8124/tools/voicelab/.
