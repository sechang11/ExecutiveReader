DOM tests

These cover the parts of the content scripts that need a real document: a TreeWalker over live elements, computed styles, and Ranges. Node cannot run them, and a fake DOM convincing enough to be worth trusting would be a larger project than the code under test, so they run here instead and are reported to whoever opened this page.

Run: node tools/serve-repo.mjs, then open http://localhost:8124/tools/domtest/.
